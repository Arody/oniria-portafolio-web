## 2. Color System

*Escala de grises con lujo sutil. La marca ya vive en B&W — lo hacemos intencional.*

### Primarios

| Nombre | Hex | Uso |
|---|---|---|
| Obsidian Black | `#0B0B0D` | Fondo principal, hero sections |
| Charcoal | `#1C1C1F` | Fondos secundarios, cards |
| Graphite | `#2A2A2E` | Bordes, separadores, fondos terciarios |
| Ivory White | `#F5F5F3` | Texto principal sobre fondos oscuros |
| Soft Mist | `#E8E8E6` | Texto secundario, descripciones |

### Acento Cinemático

| Nombre | Hex | Uso |
|---|---|---|
| Warm Champagne | `#C6A56E` | Acento primario de lujo |
| Muted Gold Dust | `#BFA16A` | Variante sutil del acento |

### Regla del dorado

El dorado **NO** es decorativo. Es **jerárquico**. Solo aparece en:

- Nombres de pareja
- Botones primarios (hover)
- Detalles de lujo y elementos destacados

## 3. Tipografía

*Contraste serif + sans limpia.*

### Headline Serif — Onírico / Elegante

| Fuente | Prioridad |
|---|---|
| Cormorant Garamond | Principal |
| Playfair Display | Alternativa |
| Canela | Premium (si se licencia) |

**Uso:** H1, nombres de pareja, frases cinematográficas.
Tracking amplio. Mucho aire.

### Sans Moderna — Cine actual

| Fuente | Prioridad |
|---|---|
| Neue Haas Grotesk | Principal |
| Inter | Web friendly / fallback |
| Satoshi | Alternativa moderna |

**Uso:** Body, navegación, botones, captions.

### Jerarquía Web

| Elemento | Tamaño | Familia |
|---|---|---|
| H1 | 64px | Serif |
| H2 | 40px | Serif |
| H3 | 20px | Sans, uppercase, letterspacing 2px |
| Body | 16px | Sans |
| Caption | 12px | Sans, color mist |

---

## 4. Layout System

*El grid debe sentirse editorial.*

### Regla clave

**Mucho espacio negativo.** Margen lateral amplio, imágenes full width, secciones que respiran.

### Estilo compositivo

- Imagen dominante
- Texto minimal
- Botón discreto
- Nada de cajas cargadas

### Principios de composición

1. **Margen lateral amplio** — Espacio que respira en cada sección del sitio.
2. **Imágenes full width** — Las fotografías dominan, el texto acompaña.
3. **Secciones que respiran** — Nada de cajas cargadas. Editorial puro.

---

## 5. Componentes Web

### Botones

**Primary:**

- Fondo negro, texto blanco, bordes rectos
- Hover: fondo champagne `#C6A56E`, texto negro

**Secondary:**

- Outline blanco, fondo transparente
- Hover: fondo blanco al 5%

### Navegación

- Fondo transparente al cargar
- Logo blanco centrado
- Al hacer scroll → fondo negro con blur
- Menú minimal, sin dropdown

### Cards de películas

- Hover: oscurece imagen
- Aparece texto con nombre de pareja y locación
- Ejemplo: *"Montse & Salva" — San Cristóbal, 2026*

---

## 6. Estilo Fotográfico

### Siempre

- Contraste fuerte — luces y sombras marcadas
- Bokeh cálido — fondos difusos con tonos dorados naturales
- Blanco y negro editorial — como lenguaje narrativo
- Close-ups emocionales — detalles íntimos que cuentan historias
- Movimiento natural — captura orgánica, nunca posada
- Si hay color → cálido cinemático

### Nunca

- Saturación fuerte
- Colores chillones
- Filtros trendy
- Edición sobre-procesada

## 8. Motion System

*Tu marca ES movimiento.*

### Principios de animación

| Propiedad | Valor |
|---|---|
| Estilo | Fade lento, ease in-out |
| Carácter | Cinemático, nunca elástico |
| Duración ideal | 400ms – 600ms |
| Rebotes | Nunca. Gravedad elegante. |

Las animaciones deben sentirse como una película revelándose, no como una app cargando.
